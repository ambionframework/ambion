## LinkedIn (PDF ambion-0.7.0-linkedin-carousel.pdf)

Ambion 0.7.0 is out.

Ambion is an open-source TypeScript kernel where agents and people work together in a shared room. If you have built one agent, you know the loop, the tools, and the session. Ambion adds what comes next: several agents on different harnesses, one record, and people in the same conversation.

- Define your agents on Pi, the Claude Agent SDK, or Codex. Every agent holds the same tools: files, shell, repositories, and skills.
- Start a room. Agents read in parallel, speak when they have something to add, and stay silent when they do not.
- Let people in. New in 0.7.0: breakout rooms for background work that a person can visit, and widgets that a person can press.

A journal keeps every message, so a restart loses nothing.

npm install @ambionframework/ambion
https://github.com/ambionframework/ambion/releases/tag/v0.7.0
