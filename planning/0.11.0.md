# 0.11.0: The settled room

**0.11.0 settles the interface of the room before the promise.** Each
item changes an export or a journal body, so each one lands before
[1.0.0](1.0.0.md). Two items remove concepts from the kernel: a close
becomes a message, and attention replaces seating.

**Evidence:**

- A close where a person spoke wakes the summary writer as an ordinary
  respond activation. A close where no person spoke wakes nobody.
- Every agent of `agents` is in the room from its start. No entry, tool,
  option, or prompt block names a reserve, a seating, or a fixed seat.
- An agent changes its own attention, and the summary writer changes the
  attention of any agent. Another agent that tries is refused. The host
  changes any attention.
- An agent cannot set the summary writer to `none`. The host can.
- A seat at `named` wakes only for a message to it. A seat at `none` wakes
  for nothing and refuses a direct delivery.
- A change that widens the attention of an agent wakes it with the
  record. A change that narrows it wakes nobody.
- The tool list of a seat stays the same for the whole room.
- A resume with a new definition starts that agent at `broadcast`, and
  the recomposition records the level.
- The `assistant` option gives the same room as its expansion by hand.
- A list where a kind repeats or follows a catch-all is a refusal.
- The golden journals, the export snapshot, the Cloudflare tests, and the
  changelog change with each item. `pnpm rule:check` passes on each rules
  file that changes.

## The items

**SR1. A close is a message.** A close that routes to the summary writer
makes the summary an ordinary respond activation. The `closed` activation
source, `owed.ts`, `closedLeases`, `closeFor`, and `summaryWriter` on the
close entry go. Due work becomes one list, and a scheduled say becomes one
entry. The review of 2026-10-02 priced the change:

- **The purpose moves into a rule.** A summary reads to its close, reads
  the preferences of the person, and writes one summary for each person.
  These become rules on the kind of the message that woke the writer.
- **A close must not wake the writer in a loop.** A close routes to the
  writer only when a person spoke in its range, as `summaryVerdict` says
  today.
- **The tools still branch.** A summary `say` drops `readThrough`, holds
  no agent tools, and ends after the last recipient.
- **The writer is an ordinary agent.** The room option `summaryWriter`
  names the agent that a close wakes.

**SR2. Attention replaces seating.** A room has a reserve, `seat` and
`unseat` tools, `room.seat` and `room.unseat`, fixed seats, `seating:
false`, and a `reserved` field on the composition. Each one exists so
that an agent can be in the room and not wake. Attention already says
when a seat wakes, so one value can carry both.

- **Every agent of `agents` is in the room.** No reserve exists. A room
  option `attention` maps a name to its starting level. An agent with no
  entry starts at `broadcast`. `seats` goes.
- **The scale stays:** `none`, `named`, `broadcast`, and `presence`. An
  agent that reacts only when named sits at `named`. An agent that the
  host turns off sits at `none`.
- **One tool `attention({ name, level })`.** An agent changes its own
  level. The summary writer changes the level of any agent, because the
  kernel knows the writer and knows no assistant. The host calls
  `room.attention(name, level)`. `seat`, `unseat`, `room.seat`, and
  `room.unseat` go.
- **The room refuses three changes.** An agent cannot set the summary
  writer to `none`, so a close always has a writer; the host can. A name
  of a person is a refusal. An agent at `none` cannot raise itself; the
  host or the summary writer brings it back.
- **A widening change wakes the agent.** A change to a wider level wakes
  the agent with the record, as a seating does today. A narrowing change
  wakes nobody.
- **One entry kind for a change of attention.** The composition records
  the starting level of each agent, so the roster has one stored source.
  A recomposition keeps the levels that the journal holds. A definition
  that the journal does not know starts at `broadcast`, and the
  recomposition records its level.
- **`fixed` goes, and `attention: false` replaces `seating: false`.** No
  agent leaves, so nothing needs a guard against removal. The start
  option `attention: false` leaves the `attention` tool out of every seat.
  `packages/canvas/src/cast.ts`, `packages/canvas/src/types.ts`, and
  `packages/cloudflare/src/room-object.ts` change with it.
- **A level of `none` drops the scheduled says of that agent**, as an
  unseating does today.
- **The canvas follows.** A breakout room starts its workers at
  `broadcast` with `attention: false`. The bridge reads an opener at
  `none` as absent.
- **Cloudflare follows.** `RoomObject.seat` and `RoomObject.unseat` go,
  and `room.attention` travels on the wire.

**SR3. The `assistant` option over the new roster.** The option stays as
a shorthand. It expands into an `agents` entry, an `attention` entry at
`broadcast`, and the `summaryWriter`, so the assistant gets the right to
change the attention of other agents. `@ambionframework/assistant` keeps
its name and its summary guidance. Its membership guidance speaks of
attention, and the three strings in `packages/assistant/src/index.ts`
that name seat, unseat, and reserve change. `docs/assistant.md` states
the expansion.

**SR4. The order of an execution list.** `route` in
`packages/ambion/src/execution/route.ts` takes the first execution that
serves a kind, and an execution with no `kind` serves every kind. A kinded
execution after a catch-all never runs. The room refuses a list where a
kind repeats or follows a catch-all.

**SR5. A review of the exports.** Each export has a user in a package, an
example, or a test, or it goes. The export snapshot after this step is
the interface of 1.0.0.

## Decisions taken

| Decision                                        | Reason                                                   |
| ----------------------------------------------- | -------------------------------------------------------- |
| A close is a message                            | One kind of activation, and one list of due work         |
| The `assistant` option stays as a shorthand     | A host names one agent and gets a working room           |
| Attention replaces seating                      | One value says whether and when an agent wakes           |
| An agent changes its own attention              | It can step back from a room or ask to hear more         |
| The summary writer changes the attention of all | The kernel knows the writer; the assistant is the writer |
| No agent sets the summary writer to `none`      | A close where a person spoke always has a writer         |
