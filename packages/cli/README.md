# @ambionframework/cli

The `ambion` binary. Reports its version; `dev`, `deploy` and `init` arrive with
the runtime.

```sh
npx ambion --version
```

Requires Node **>= 22.19** (or >= 23.6). Installing needs a token; see the
[repository README](https://github.com/ambionframework/ambion).

Apache 2.0.
