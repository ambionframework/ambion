# @ambionframework/ambion

The Ambion runtime.

> **Scaffold.** This package is a placeholder. The framework — workspace, agent,
> task, subscription, timer, and the one invariant that ties them together —
> lands in a follow-up. What ships today is an empty package that builds,
> type-checks, packs and publishes, so the release path is proven before there
> is anything to release.

```sh
npm install @ambionframework/ambion
```

See the [repository README](https://github.com/ambionframework/ambion) for what
the framework is meant to be, and
[`docs/toolchain.md`](https://github.com/ambionframework/ambion/blob/main/docs/toolchain.md)
for how this package is built and released.

Apache 2.0.
