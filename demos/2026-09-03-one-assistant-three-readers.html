What this change built

The assistant binds at startSession. StartSessionOptions takes assistant as a required field beside agents, and the room seats it at none in the same loop that seats the products. It is composition, like an agent: present for the whole run, listed in every roster, and never activated in a room nobody visits. startSession refuses an assistant that did not come from defineAgent, one that holds tools, one that names a workspace, and one whose name an agent already holds. defineHuman no longer takes one.

How a person reads lives on the person. defineHuman gains one optional field, preferences. The room keeps it as run state from the person’s latest visit, and keeps it after they leave, so an exchange that outlives a visit is still written their way. At the one activation where the assistant writes for somebody, its system prompt names them and carries their paragraph. The roster every seat reads carries the identity alone: 1,010 characters of the first product context, of which the assistant is one line of 124. In the run before this one, the same roster described one assistant per visitor and the people carried “brings priya-assistant”.

One seat, one activation at a time. The assistant holds one activation, so two people owed at once are written for one after the other: a close that finds it drafting leaves that person owed, and the room activates the assistant again for them when the draft ends. A person whose draft failed waits for the seats to stop again, so a model that keeps failing never retries on its own end. This run asked its questions in turn, so no two people were owed at once; the test suite holds the case.

The fold paragraph follows the record. A seat used to be told how to read a fold from the moment somebody brought an assistant. It is now told once the record holds a summary, which is the precise condition, and RoomView lost the field that gated it.

What a host reads changed by two fields. An agent seat that is the assistant carries assistant: true in place of owner; a person’s seat no longer names one. Every summary on the record has the same from and a different to, and the fold above each one still names the person it was written for.
