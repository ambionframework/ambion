# Kestrel Yard, Block C — the site drive

The shared drive for Block C. Every product on the site reads it, and every
product writes to the diary. State that a product owns (tasks, deliveries,
hours) lives in that product, not here. This drive holds the documents the
site works to.

| Path                                    | What                                                | Written by                          |
| --------------------------------------- | --------------------------------------------------- | ----------------------------------- |
| `/site/pour-plan/level-3-slab.md`       | The method statement for the Level 3 slab pour      | The temporary works coordinator     |
| `/site/weather/week-35.md`              | The forecast for the week, issued each morning      | The site office                     |
| `/site/inspections/building-control.md` | How building control inspections are booked         | The site office                     |
| `/site/diary/YYYY-MM-DD.md`             | The site diary: one file per day, decisions and why | Every product, one entry per change |

Diary entries are appended, never rewritten. An entry is one line: the time,
who wrote it, and what changed.
