# Library

**This directory holds short datasheet summaries for one toy Arduino kit.**
The agents read these files before they claim a specification. Each file
names its part, its key limits, and the formula a design needs.

These are simplified summaries for a runnable example. They are not the
manufacturer datasheets. Confirm any real design against the real datasheet.

| File                | Part                             |
| ------------------- | -------------------------------- |
| `arduino-uno-r3.md` | Arduino Uno R3 board             |
| `led-5mm.md`        | 5 mm through-hole LED            |
| `resistors.md`      | Carbon-film resistors, E12       |
| `hc-sr04.md`        | HC-SR04 ultrasonic distance unit |
| `pushbutton.md`     | Momentary push button            |
